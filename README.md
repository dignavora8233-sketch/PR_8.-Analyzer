# 🔢 NumPy Analyzer

A beginner-friendly Python project built using **NumPy** to perform different array operations, mathematical calculations, searching, sorting, filtering, combining, splitting, and statistical analysis.

## 📌 Project Overview

**NumPy Analyzer** is a menu-driven Python program that allows users to create and analyze NumPy arrays.

The project demonstrates important NumPy concepts such as:

* 1D, 2D and 3D arrays
* Array reshaping
* Mathematical operations
* Combining and splitting arrays
* Searching values
* Sorting arrays
* Filtering values
* Aggregate functions
* Statistical functions

## ✨ Features

### 1. Create a NumPy Array

The program allows you to create:

* 1D Array
* 2D Array
* 3D Array

Example:

```text
Enter elements: 10 20 30 40 50
```

Output:

```text
[10 20 30 40 50]
```

---

### 2. Mathematical Operations

The program supports:

* Addition
* Subtraction
* Multiplication
* Division

Example:

```text
Array 1: [10 20 30]
Array 2: [1 2 3]
```

Addition:

```text
[11 22 33]
```

---

### 3. Combine or Split Arrays

Arrays can be:

* Combined using `np.vstack()`
* Split using `np.split()`

Example:

```text
Combined Array:
[[1 2 3]
 [4 5 6]]
```

---

### 4. Search, Sort and Filter

The program provides:

#### Search

Checks whether a particular value exists in the array.

#### Sort

Sorts the array using:

```python
np.sort()
```

#### Filter

Displays values greater than a given number.

Example:

```text
Array: [10 25 15 40 5]
Value: 20
```

Output:

```text
[25 40]
```

---

### 5. Aggregates and Statistics

The project performs different statistical calculations:

* Sum
* Mean
* Median
* Standard Deviation
* Variance

NumPy functions used:

```python
np.sum()
np.mean()
np.median()
np.std()
np.var()
```
